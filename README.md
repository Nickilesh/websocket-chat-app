
A real-time chat application built using Spring Boot, WebSockets, and Docker. This application allows users to chat with each other in real-time.

## Technologies Used

- **Backend:** Spring Boot (Java 21)
- **WebSockets:** Spring Boot WebSocket support
- **Frontend:** HTML, CSS, JavaScript (optional if you're implementing a frontend)
- **Docker:** For containerization of the application
- **Render:** For deployment

## Live Demo

You can access the live demo of the chat application here:

[Live Chat Application](https://chat-app-e5yk.onrender.com/chat)

## Features

- Real-time messaging
- WebSocket-based communication
- Simple chat interface
- User authentication (if added to the application)
- Deployable using Docker and hosted on Render

## Prerequisites

- Java 21 (or above)
- Maven
- Docker (for building and deploying the application)
